# Sales Data Analysis

This project analyzes historical sales data stored in a SQLite database. It uses a Jupyter Notebook to perform data extraction, transformation, and visualization, helping to uncover key business insights such as top-performing products, regional sales trends, and revenue summaries.

## 📂 Files

- `sales.db`: SQLite database containing the raw sales data.
- `sales_summary.ipynb`: Jupyter Notebook with SQL queries, data processing, and visualizations.
- `output.pdf` : Shows the table and the histogram output.

## 📊 Features

- Connects to SQLite database
- Performs SQL-based data extraction
- Generates summaries and visualizations (e.g., total sales, product rankings, etc.)
- Provides insights into customer behavior and sales trends

## 🛠️ Requirements

To run this project, you’ll need:

- Python 3.x
- Jupyter Notebook
- SQLite3
- Pandas
- Matplotlib / Seaborn
